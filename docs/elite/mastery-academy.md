# Mastery Lab

Fifteen advanced modules build on the twelve existing multilingual audio lessons. They cover architecture, CLI, MCP, agents, RAG, tools, testing, multilingual behavior, speech engineering, Flows, Studio, automation, governance, cost and deployment. Every module includes an objective, explanation, concrete project example, process visualization, code/contract, exercise, self-review criteria, official references and an explicit limitation.

The interface supports search, skill categories, module navigation, an evidence explorer, downloadable Markdown guides and browser-local notes/progress. Tool-boundary examples are deterministic and explicitly labeled. Related recordings reuse existing genuine Academy output; they are not presented as narration of the new advanced modules.

Progress is self-reported. It is not an official ElevenLabs certification, exam, LinkedIn credential or identity-verified assessment. Malformed storage is handled conservatively, note lengths are bounded and exercise content never triggers a paid request. Browser QA covers filtering, notes, checklists, reload persistence, downloads and mobile overflow.
