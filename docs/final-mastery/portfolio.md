## Executive version

Built a multilingual voice-AI case study that separates retrieved facts from human authority. Combined server-side ElevenLabs integration, native creative workflows, recorded media, authenticated access and reproducible evaluation tooling. Added an offline native-result importer that preserves unknown billing, a static failure explorer and adversarial multilingual contracts for exact tool arguments and structured facts. Produced developer education and a validated EPUB with a later explicitly approved 10,000-credit budget for native learning and Studio QA.

This portfolio demonstrates engineering decisions and transparent evidence. Current gaps are operational acceptance, native template QA, independent human evaluation and authentic adoption. No customer claims, awards, official certification, fabricated testimonials or audience metrics are included.
