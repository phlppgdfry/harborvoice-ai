# AgentProof design rationale

An evidence workbench, with a navy workspace rail (#102d43), white inspection surfaces (#ffffff), cool canvas (#f6f8fc), readable ink (#22384c), blue actions (#215eaf) and scoped red failures (#99383c). Inter SemiBold for the product name/headline; system text for dense reading. Existing licensed font only.

Layout: fixed workspace navigation; run selector; four factual counts; broad scenario table beside a persistent failure inspector. The memorable element is the failure anatomy, where expected/observed behavior and tool trace sit together. No generated decorations or unmeasured reliability graphs. On mobile, navigation becomes a horizontal row and inspector follows the table. Filters, empty state, downloads and methodology are real interactions.

Review against brief: presenting 100% candidate fixture success as product reliability would mislead. The design labels both policies as fixtures, puts the limitation above the metrics and isolates the historical provider study. Unknown latency stays a written measurement gap. No invented testimonials or unsupported trend curve.
