# AgentProof pilot testing kit — not launched

Goal: 3–5 consenting volunteer developers after owner approval. No invitations sent, no participants, no feedback or adoption metrics.

## Invitation draft

I am building AgentProof, a small tool for inspecting voice-agent evaluation evidence. Would you try a 15-minute no-registration exercise? The demo uses fictional data and scripted fixtures, not a live microphone. We want to learn whether failures and limitations are understandable. Participation is optional; no account key or customer data is needed. Please reply only if interested. Date and approved preview URL will be supplied after launch review.

## Participant instructions / usability test

1. In your own words, describe the product after 60 seconds. Avoid guidance from the facilitator.
2. Find a failed tool-error case and explain the expected/observed difference.
3. Compare the corrected policy. Explain what its passing check does and does not prove.
4. Export evidence and locate the source commit and one limitation.
5. Download optional feedback. Share only if you choose through an owner-approved channel.

Target: at least 4/5 participants locate a failure within two minutes and explain that fixtures do not establish voice reliability; at least 3/5 find a useful engineering action. These are prospective goals, not results. Record completion, time, confusion and facilitator interventions. Do not convert five purposive participants into a population claim.

## Questionnaire

What problem does this solve? Which label confused you? Could you identify a failure and recommend a fix? Did any displayed number imply more evidence than exists? Would you revisit it, and for which task? What should be removed? Rate task clarity 1–5, optionally explaining why. No mandatory email, employer, demographic or voice sample.

## Consent and privacy text

Participation is voluntary; you may stop or skip questions. No recording by default. We request permission to retain anonymized task notes for 30 days to improve the product. Do not include confidential information. Organizer must provide a real private contact/deletion route and confirm the lawful collection setup before collecting data. Declining data retention does not prevent using the demo. Quotes/testimonials need separate explicit approval.

## Issue workflow and backlog

Private notes → remove identifiers → reproduce with synthetic data → classify P0 security/claim integrity, P1 blocked task, P2 confusion, P3 enhancement → create sanitized issue → test fix → retain before/after task evidence. Public tracker is linked, never automatically posted to. Backlog: independent annotation review, balanced language corpus, tool-argument assertions, provider receipt importer, authenticated live-run design. None is presented as feedback-derived until real feedback exists.
