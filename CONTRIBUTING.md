# Contributing

Use fictional data and preserve source/permission boundaries. Start with `npm ci`, `npm run check`, `npm run elite:validate` and the three browser walkthroughs. Do not run paid generation as an incidental test. Add a concrete scenario for a new agent behavior and distinguish deterministic fixtures from provider results.

Agent changes need a drift preview before a remote update. Native Studio/Flow edits must be reconciled manually. Never commit `.env`, `var`, signed URLs, OAuth tokens or personal recordings. Include the observed test scope and limitations in your pull request.
