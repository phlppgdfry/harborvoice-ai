# Workshop launch and registration checklist

Materials support a 90-minute workshop with zero provider credits: 10 minutes business boundaries; 15 tool contracts; 20 starter exercises; 15 AgentProof failure comparison; 15 EN/NL/FR argument/fact contracts; 10 evidence export; 5 feedback. Optional live demonstrations require a separately approved, quoted envelope and cannot be required for participation.

Before registration opens, confirm the instructor, date/time/timezone, venue or meeting platform, capacity, step-free access, quiet space, caption/text alternatives, reliable power and no-key starter instructions. Rehearse on a clean Node 24 checkout: `npm ci`, `npm run check`, `npm run test:contracts` and the workshop starter tests. Keep recorded media available offline when network access fails.

Registration should request only name or preferred name, email for essential logistics and optional accessibility needs via a private route. Owner must name the contact, retention deadline and cancellation process. Do not collect API keys, employer/customer records or sensitive accessibility details in a public sheet. Explain photography/recording separately and default to no recording.

Publish only after owner approval. If using official Ambassador branding or seeking reimbursement, obtain provider event/budget approval first. Do not imply sponsorship from submitting an application. Confirm venue costs from actual quotes; do not spend before approval. No date, venue, attendee count or sponsorship is claimed here.

Instructor contingency: use the printed handout and prerecorded examples if an account or native interface fails. Never troubleshoot by sharing a participant's key on screen. Pair learners and offer English/Dutch/French written prompts. Optional feedback is voluntary; report actual attendance and observed tasks only after delivery. Delete registration data on the adopted deadline and review any testimonial before publication.
