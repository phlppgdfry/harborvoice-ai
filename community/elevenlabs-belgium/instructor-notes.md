# Instructor runbook

Audience: developers, IT professionals, business analysts, founders and students. English delivery with Dutch/French exercises. No prior paid plan. Prerequisites: Node 24, Git or downloaded repository, text editor; optional participant-owned ElevenLabs account. Never project personal credentials.

| Minutes | Activity                                    | Concrete outcome                                                   |
| ------- | ------------------------------------------- | ------------------------------------------------------------------ |
| 0–8     | What voice AI does; evidence distinctions   | Participants separate text, audio and fixture evidence             |
| 8–20    | First agent, guided dashboard demonstration | Language, first message, prompt and voice understood               |
| 20–35   | Knowledge and tools                         | Fictional lookup input/output contract and authority boundary      |
| 35–50   | Failure exercise                            | Missing reference, unknown record, invalid response and timeout    |
| 50–65   | Evaluate and inspect AgentProof             | Find failure, compare fixture fix, export scoped report            |
| 65–77   | Multilingual and safety                     | Translate intent; preserve authorization and escalation invariants |
| 77–84   | Deployment and cost                         | Server-side credentials, bounded usage and shared spending         |
| 84–90   | Questions and follow-up                     | Each participant names one unresolved measurement                  |

Before event: run starter tests, build app, open local preview and slides. Confirm projector contrast and readable body text. Use approved prerecorded existing Academy/HarborVoice media only if it can be played locally; captions/transcript should accompany it. Do not depend on network or a private native resource for core teaching.

First-agent demo: instructor may show an already authorized read-only dashboard. Explain first message, chosen language and prompt constraints without saving changes to Nora. A participant can optionally create their own sandbox agent in their own account outside the zero-cost path. Never use the organizer key in shared files or browser code. Show a fictional `HV-101` record and a policy that a customs hold cannot be overridden by user wording.

Exercise facilitation: ask participants to predict the outcome before running each test. When `lookup` throws, demonstrate why a friendly answer must not claim release. For invalid response schemas, compare recover versus escalate and justify your domain policy. The provided starter is a business boundary, not a simulated LLM.

AgentProof exercise: baseline has 30 deliberately scripted failures; corrected fixture passes by policy construction. Ask participants why that does not prove a real agent is reliable. Show the separate six-case historical provider report, including missing transcripts/latency. Avoid aggregating the counts.

Multilingual exercise: ask Dutch or French speakers to rewrite a missing-reference request. The expected action remains clarification. Do not call translation quality objective without qualified review. Demonstrate how code-switching can preserve a business invariant even when pronunciation changes.

Cost: required local path costs **0 provider credits per participant**. Optional live test estimate uses actual model/account price and bounded duration checked just before the workshop, not an invented flat rate. Planning formula: participants × allowed sessions × maximum duration × verified credits/minute + conservative model/tool overhead. Instructor must reconcile the current quote and participant allowance; if unavailable, stay offline. Organizer funds no accounts.

Debrief rubric: identify failure, explain contract, propose authorized fix, distinguish evidence types. No certificates of ElevenLabs expertise or endorsement. Get explicit consent before retaining notes; use the pilot kit privacy policy. Collect optional feedback only after providing a private contact and deletion route.
