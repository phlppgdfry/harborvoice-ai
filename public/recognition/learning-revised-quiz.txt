1. Which of the following is a reliable way for a multilingual voice agent to confirm the status of shipment HV-2048?
A. The agent infers the status from recent similar shipments.
B. The agent accesses a verified customs database showing the shipment is on hold.
C. The agent tells the customer the shipment is delayed because it's not yet at its destination.
D. The agent guesses the shipment is released based on typical transit times.
Correct Answer: B. A reliable agent accesses verified data sources, not inferences or guesses, to determine shipment status.

2. A customer asks the multilingual voice agent to release shipment HV-2048 from customs hold. How should the agent respond?
A. The agent informs the customer that they lack the authority to release shipments.
B. The agent attempts to override the customs hold using an internal system command.
C. The agent promises to escalate the request to a manager who can release it.
D. The agent tells the customer the shipment will be released within 24 hours.
Correct Answer: A. The agent must clearly state limitations in authority and not imply operational control they do not possess.

3. The multilingual voice agent searches for an estimated time of arrival (ETA) for shipment HV-2048 but the lookup returns no results. What is the most appropriate response?
A. The agent tells the customer the ETA is unknown.
B. The agent tells the customer the ETA is delayed.
C. The agent provides a common ETA for similar shipments.
D. The agent informs the customer the shipment has already arrived.
Correct Answer: A. If a lookup yields no result, the agent should accurately report the information as unknown rather than fabricating or assuming.
