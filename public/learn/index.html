Start in two minutes

git clone https://github.com/phlppgdfry/harborvoice-ai.git
cd harborvoice-ai
node --test community/elevenlabs-belgium/starter/agent.test.mjs

Eight passing tests means you are ready for Tutorial 1 and the workshop. You need Node.js 24 and nothing else.

The tools used

  • HarborVoice AI workbench — the public demo of the fictional terminal agent.
  • AgentProof — a static page for exploring evaluation evidence.
  • AgentOps Kit — a small library and CLI for configuration checks, scenario evaluation and reports.
  • Source code and release v2.2.0.

What these pages do not claim

  • All data is synthetic. No real customers, shipments or callers are involved.
  • The offline tests check your own code and contracts. They do not measure how a language model or a voice behaves.
  • HarborVoice is an independent project. It is not affiliated with, sponsored by or endorsed by ElevenLabs.
  • No workshop has been delivered yet, and there are no users, attendees or testimonials to report.
