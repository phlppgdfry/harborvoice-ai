# ElevenLabs AgentOps Kit

Independent toolkit v0.2.0 release candidate. Inspect configuration, compare drift, replay outcome/tool contracts and export scoped evidence without a provider call. Not an ElevenLabs product or security certification.

## Safe quickstart

From this repository, Node 24:

```sh
npm ci
npm run check --prefix packages/agentops-kit
node packages/agentops-kit/dist/cli.js inspect packages/agentops-kit/examples/config.json
node packages/agentops-kit/dist/cli.js validate packages/agentops-kit/examples/config.json
node --import tsx scripts/phase3/benchmark.ts
node packages/agentops-kit/dist/cli.js report benchmarks/voice-ai/results/baseline.json html > /tmp/agentops-report.html
```

The package runtime uses only Node built-ins. In a separate checkout, install package devDependencies before building. `inspectElevenLabs` accepts an injected official SDK client; SDK is an integration-test devDependency, not a runtime requirement. No implicit credential loading, network calls, evaluation retries or paid CLI commands.

```ts
import { evaluate, inspectElevenLabs } from "harborvoice-agentops-kit";
// Server only; client is your official ElevenLabsClient with least-privilege access.
const snapshot = await inspectElevenLabs(client, agentId);
const results = await evaluate(scenarios, {
  evidenceType: "fixture",
  execute: async (scenario) => recordedObservations[scenario.id],
});
```

Supply independent observations. Returning expected values directly only tests the reporter, not your agent. `evaluate` checks exact outcome and unordered tool-set equality, preserves repeats and converts transport failures into failed evidence without exposing error messages. Optional `expected.toolCalls` checks ordered tool names and exact JSON arguments; `expected.facts` checks exact structured facts and rejects extra claims. Missing observations fail these contracts. `failedAssertions` identifies the violated dimension. This does not judge semantic transcript truth, fluency or audio performance. For SDK `runTests`, use a separate authorized server adapter and reconcile suite completion/receipts before converting to this schema; `submitNativeSuite` and `readNativeSuite` expose the current official SDK interfaces through a structural adapter. Submission requires an externally implemented account-wide reservation guard, isolated branch, 1–12 tests and 1–2 repeats. No guard implementation is supplied: its typed scope is an integration contract, not proof of distributed coordination. The callback must persist reservations, retain ambiguous/failed holds and record invocation IDs under the lock. No automatic retry/polling is supplied. The offline `importNativeReceipt` accepts API snake_case or SDK camelCase metadata, rejects identity mismatches, duplicate/unmapped runs and invalid costs, and omits raw transcripts. It preserves missing credit totals as null, reports known subtotals separately, and never releases a reservation. Imported native pass status is not converted into application benchmark success. Raw suite reads may contain sensitive data and need redaction before export. Tests exercise mocks only; no live submission was performed.

## Public API v1

`inspect`, `redact`, `version`, `diff`, `validate`, `evaluate`, `regression`, `wilson`, `budget`, `report`, `inspectElevenLabs`, `reserve`, `receipt`, `ledgerState`, `submitNativeSuite`, `readNativeSuite`, `importNativeReceipt`. Declaration files are generated by strict TypeScript. Result/report schemas have explicit v1 versions; 0.x can change with documented minor releases. `diff` uses JSON-pointer paths; arrays are atomic. Secret rotations produce redacted changes, while public hashes deliberately ignore secret-only differences. Inspect returns all provider config fields after redaction rather than assuming a stable hand-maintained subset.

CLI: `inspect config.json`, `diff before.json after.json`, `drift before.json after.json`, `validate config.json`, `budget policy.json`, `import-native receipt.json expected.json`, `report evidence.json [json|markdown|html]`. Validation exits 2 for high findings; malformed input exits 1. No `agentops test` command is claimed; use the typed evaluation API. Budget includes immutable reservation/receipt proposals and a conservative calculator, not a transaction lock or persisted reservation store. Persist proposals atomically before dispatch; failed/pending holds remain until confirmed final provider reconciliation. Real spending must use the existing persisted Credit Governor plus independently verified shared account coordination. See `docs/phase3/budget-report.md`.

## Security and licensing

Secret-shaped keys and URL query/credential fields are removed. Arbitrary secrets or personal data embedded in prose are not guaranteed detected. Review prompts/transcripts before publishing. Exporters escape HTML and fence-breaking content. Inputs are trusted local JSON files with a 2 MB CLI limit; do not expose this CLI as a public upload service.

MIT, original project code. No ElevenLabs source copied. Existing Credit Governor reviewed and retained in HarborVoice; package calculator supplements rather than silently replaces its persisted lifecycle. Inter font is app-only under its accompanying license.

Not published to npm. Name availability does not imply a reservation. No separate repository created: use this package until external demand justifies extraction.

## Native receipt review

Use a private downloaded invocation JSON and an independently checked expected mapping:

```json
{
  "invocationId": "suite_example",
  "agentId": "agent_example",
  "branchId": "agtbrch_example",
  "testIds": ["test_example"],
  "repeats": 1
}
```

```sh
node packages/agentops-kit/dist/cli.js import-native receipt.json expected.json
```

No API key or network connection is used. Branch identity must be present on every run; historical receipts lacking it need manual review. Source SHA-256 identifies the exact input bytes after JSON serialization, not provider authenticity. Store raw receipts privately. Final account reconciliation remains separate. See the [official test invocation contract](https://elevenlabs.io/docs/api-reference/tests/test-invocations/get).
