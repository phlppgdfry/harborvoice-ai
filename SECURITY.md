# Security

Do not post credentials or sensitive recordings in public issues. Rotate a leaked key in its official provider settings, then remove it from delivery artifacts and review repository history. This project has no published bug bounty or response-time guarantee.

Private provider keys remain server-side. Public visitors receive recorded media and a separate bounded read-only voice trial. Operator access uses a signed secure cookie; it is a single-owner demo, not enterprise identity management. See `docs/elite/security.md` and `docs/elite/limitations.md` for retention, budgeting and deployment boundaries.
